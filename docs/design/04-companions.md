# 5. Companions

Companions are both tamed and story-given/bestowed — each with their own lore, mechanically distinct from
Interactive NPCs (no shop role, no village placement).

| Type | System |
|---|---|
| Tamed | Simplified loyalty meter (Wary -> Comfortable -> Loyal -> Devoted, ~3-4 tiers). Sourced via the Wild/Beast tree (taming, ranching, the Stable/Sanctuary structure). Species-level lore rather than personal backstory. |
| Story-Given | Full 6-tier relationship meter, same depth as Interactive NPCs. Tied to narrative milestones and/or NPC relationship milestones (e.g. a Close Friend NPC eventually joins as a companion). Unique dialogue and personal backstory. |
| NPC-Granted (Creature) | Bestowed at Confidant tier (4/6) by a specific Interactive NPC whose trade doesn't translate directly into dungeon-useful action — see 03-npc-relationships.md, 4.6. The creature carries that NPC's flavor/theme (a Perfumer gifting a scent-warding animal, a Beekeeper summoning a giant bee) even though the NPC themselves never enters the dungeon. Mechanically a Story-Given companion (full combat/loyalty framework) with a fixed origin story tied to the granting NPC. |

All three types share a common underlying Companion framework (loyalty, combat assist, following behavior).
Wild/Beast tree capstones (Alpha Bond, Menagerie Keeper) buff **all** companions regardless of origin, so the tree
stays relevant even if a player's favorite companion came from the story, a granting NPC, or taming.

**Distinct from Dungeon Escorts (4.6):** an NPC-Granted Creature Companion is a pet/mount-style Companion per this
section's framework. A Dungeon Escort is the NPC themselves physically accompanying the player into the dungeon —
a different system entirely, for NPCs whose trade *does* translate into direct dungeon utility. See
03-npc-relationships.md, 4.6 for the full split and which NPCs fall into which category.
